# BRISC Study Tracker

A beginner-friendly web page created for Workshop 02.

- Open `index.html` in a browser to try it.
- `index.html` contains the page.
- `styles.css` formats the page.
- `app.js` adds tasks when the button is clicked.

The feature branch exercise will add a separate grade checker under `features/grade-checker/`.
Later, the direct-to-main exercise will link to the checker from this page.
